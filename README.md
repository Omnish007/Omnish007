## About

I work across the stack, from responsive interfaces and reusable React components to API design, data modeling, and background workflows. I care about making software easier to understand, safer to change, and more dependable in real use.

## Engineering approach

**Architecture** — focused modules, clear responsibilities, and pragmatic design decisions.

**Reliability** — validation, authorization, meaningful tests, and deliberate handling of failure paths.

**Performance** — responsive interfaces, efficient data access, and attention to the experience of the people using the software.

**Delivery** — readable documentation, repeatable workflows, and changes that can be verified rather than merely assumed to work.
